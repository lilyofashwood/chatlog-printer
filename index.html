Save Claude conversations on your computer. Keep the code spacing, the tables, the curious turns. Print a clean transcript you can actually read.

This is an invented sample. Trying it saves only this sample in this browser's demo library; it does not connect to Claude.

Install the Chrome extension
  1. Download the private release ZIP from the repository's Releases page and extract it.
  2. Open chrome://extensions, enable Developer mode, and choose Load unpacked.
  3. Select the extracted folder containing manifest.json.
  4. Open a Claude conversation and choose Chatlog Printer from the toolbar.

The demo and installed extension have separate local libraries. The extension still needs testing against a signed-in Claude conversation; this sample does not prove live capture.
